Problem Understanding & Solution Design (8 Marks)

The Challenge of Modern Financial Fraud

Financial institutions process billions of transactions daily where traditional static rule engines fail against evolving attack vectors.

⚠️

Legacy Limitations

  • High False Positives: Legitimate customer purchases get declined unnecessarily.
  • Slow Manual Reviews: Hours or days pass before anomalous vectors are triaged.
  • Carding Bot Bursts: Rapid sub-second micro-charges bypass single-transaction threshold rules.
  • Opaque Decisions: Customers and auditors receive zero explanation why transactions were declined.
🛡️

NeuroShield Solution Architecture

  • Sub-10ms Inference: Microsecond parallel execution of multi-factor AI strategies.
  • Explainable AI (XAI): Transparent attribution breakdown (+35% Amount spike, +40% Impossible travel).
  • Self-Service User 2FA: Users verify or freeze compromised cards instantly.
  • Dynamic Active Learning: Closed-loop weight recalibration from admin and user feedback.

AI Anomaly Detection Ensemble

Multi-Dimensional Threat Detection

Transactions are evaluated across 4 orthogonal dimensions to yield a deterministic Risk Score from 0 to 100.

📊

1. Dynamic Z-Score Outlier (Amount)

Calculates deviation from the cardholder's historical spending mean ($μ$) and standard deviation ($\sigma$). Outliers with $Z \ge 2.5\sigma$ are immediately flagged.

zScore = (amount - userMean) / stdDev;
if (zScore >= zThreshold) { risk = 75.0; }
⚡

2. Sliding-Window Velocity Tracker

Thread-safe sliding window tracking transaction frequency per account. Detects carding bot attacks and rapid-fire bursts within seconds.

velocity = tracker.recordAndGetVelocity(userId);
if (velocity > maxAllowed) { flagBurst(); }
🌍

3. Haversine Impossible Travel

Calculates physical distance between consecutive transaction coordinates divided by elapsed hours. Detects impossible travel speeds exceeding 800 km/h.

speedKmH = haversine(coordA, coordB) / hours;
if (speedKmH > 800.0) { flagImpossibleTravel(); }
💻

4. Device Isolation & Risk Scoring

Flags unrecognized device fingerprints, nocturnal off-hour executions, and high-risk financial tax havens or sanctioned jurisdictions.

if (isHighRiskCountry(country) || isNewDevice) {
    riskScore += isolationPenalty;
}

Relational Schema & Pure JDBC Architecture

Designed with robust relational integrity, indexes, connection pooling, and explicit JDBC DAO implementations.

🗄️

Database Schema (schema.sql)

  • transactions: Primary key ID, UUID transactionId, amount, city, country, coordinates, risk score, status, JSON XAI breakdown.
  • fraud_alerts: Linked alert records, severity (CRITICAL, HIGH), status (PENDING_REVIEW, RESOLVED), resolved_by.

Custom Servlet Filter

FraudAuditServletFilter implements jakarta.servlet.Filter. Intercepts incoming web requests to inject security audit headers and track millisecond response latency.

public class FraudAuditServletFilter implements Filter {
  public void doFilter(ServletRequest req, 
                       ServletResponse res, 
                       FilterChain chain) {
    res.setHeader("X-NeuroShield-Security", "Active");
    chain.doFilter(req, res);
  }
}
